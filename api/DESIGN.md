# 设计 token（冻结）+ 页面规格

设计目标：**像 iOS 系统应用 / Apple 宣传片**——留白多、层级靠字重和间距而不是边框和颜色、动效克制、文案极短。禁止：渐变按钮、阴影堆叠、彩色图标墙、长句子解释、表格化的表单。

## Token

```css
:root{
  --bg:#F7F7F9;      --surface:#FFFFFF;   --surface-2:#F2F2F5;
  --text:#111114;    --text-2:#6E6E73;     --text-3:#A1A1A6;
  --line:#E5E5EA;    --line-strong:#D1D1D6;
  --accent:#0A84FF;  --success:#34C759;    --warn:#FF9F0A;  --danger:#FF3B30;

  --r-card:16px; --r-pill:999px; --r-input:12px;
  --sp-1:4px; --sp-2:8px; --sp-3:12px; --sp-4:16px; --sp-5:20px; --sp-6:24px; --sp-8:32px; --sp-12:48px;

  --fs-title:28px;  --fw-title:700;
  --fs-section:17px;--fw-section:600;
  --fs-body:16px;   --fs-sub:14px;  --fs-caption:12px;

  --dur:200ms; --ease:cubic-bezier(.32,.72,0,1);
  --shadow-float:0 8px 30px rgba(0,0,0,.08);
  --font:-apple-system,BlinkMacSystemFont,"SF Pro Text","PingFang SC","Microsoft YaHei",Inter,sans-serif;
}
```

规则：只用 token，不写魔法数字；分割线用 `--line` 1px（0.5pt 观感可用 `transform:scaleY(.5)`）；圆角只用 12/16/999；深色模式由 `prefers-color-scheme` 提供同结构变量，不另做主题开关；`prefers-reduced-motion` 时关闭过渡。

## 页面

**1. 登录（/` ）**：居中一行头像（56px 圆形，成员色底 + 名字首字），点一下即进入；底部一个很轻的「管理员」文字链接。

**2. 今日（首页）**
```
9月18日 星期五                    小明 ▾        (顶栏：日期大标题 + 当前成员头像，点开切换成员)
────────────────────────────────────────────
工作
  倒垃圾                              [ 认领 ]
  拖地                小王已认领       [ 完成 ]
家务
  洗碗                小李  08:42            ✓
────────────────────────────────────────────
        [ 今日 ]  本周   本月   历史                (底部分段控件，当前项黑底白字)
```
- 行高 56px，滑动时分组标题吸顶；已完成行文字降为 `--text-3` 并加删除线感（不加图标）。
- 「认领」= 描边胶囊按钮；「完成」= 实心胶囊（accent）；点击后行内就地变化，不做整页刷新、不弹确认框。
- 空态：居中一行 `今天没有任务`。

**3. 本周 / 本月**：7 列 / 月历网格，格子内最多 3 个小圆点（按状态着色：open=--line-strong，claimed=--warn，done=--success），点格子 → 底部抽屉列出当天任务，可直接认领/完成。

**4. 历史**：按天倒序的时间线，每行 `任务 · 谁 · 完成时间`，仅此三要素。

**5. 发布任务**（右下角 56px 圆形 `+` → 底部抽屉）：
- 字段只有四个：**任务名**（大字输入，无边框，占位符即说明）、**分组**（横向胶囊选择）、**重复**（不重复/每天/每周/每月）、**谁做**（头像行，默认「谁都可以认领」）。
- 主按钮「发布」全宽 50px 高，其余全部省略（备注、提醒等放进「更多」折叠，默认收起）。

**6. 大屏模式**（`/?tv=1`，给冰箱/客厅平板）：黑底、超大字号，只显示今日未完成任务 + 已认领人，每 60s 自动刷新。

**7. /admin**：纯工具页，允许朴素（成员管理、分组管理、导出数据库、写入演示数据）。不套用上面的审美标准，但同样禁长文案。

## 技术约束

- 前端**零构建**：原生 ES 模块 + 一份 `app.css`，`go:embed` 进二进制；不引入 React/Vue/Tailwind/Font CDN。
- 必须手写：无外部字体、无外部 JS、无外部图标库（图标用内联 SVG，最多 6 个）。
- 交互只允许：淡入淡出 + 位移 ≤8px + 圆角/颜色过渡；不做弹跳、不做骨架屏。
- 移动端：`viewport-fit=cover`，安全区 padding，点击目标 ≥44px。
