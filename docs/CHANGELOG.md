# Changelog

本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## 1.0.0 — 2026-09-19

首个公开版本。

**核心**
- 无密码登录：点头像即进入，成员可随时切换
- 发布 → 认领 → 完成 两段状态，各自留「谁 / 何时」；认领用条件更新，撞车返回 409 并回传当前实例
- 一次性任务与循环任务（每天 / 每周 / 每月），生成器补齐当前自然月且按 `(chore_id, due_date)` 幂等
- 任务时间三选二：开始 / 时长 / 结束，给两个算第三个；默认当前时刻 + 10 分钟
- 成员头像上传（前端 canvas 压缩后上传，≤256 KB，存进数据文件）
- 日 / 月 / 年 日历视图：方格日历 + 状态点，箭头与左右滑动导航，翻出已加载窗口自动增量拉取
- 成员密度带（GitHub 贡献图风格，逐天四级着色）与每人「N 件 · M 分钟」统计
- 大屏模式 `/?tv=1`
- `/admin`：成员与分组管理（成员即可操作）、导出数据库、写入演示数据、**清空数据**

**工程**
- 单容器：alpine + 静态二进制，运行层约 24 MB，非 root 运行（uid 10001）
- 零第三方 Go 依赖（纯标准库）；前端零构建（原生 ES 模块，`go:embed`）
- 数据层：单文件 JSON + `RWMutex` + 原子写（temp+rename）
- 构建不依赖 Docker Hub 拉 golang 镜像（Go 工具链来自 `vendor/` 或 `CHORUS_GO_MIRROR`）
- 环境变量 `CHORUS_*` 优先、`CHORES_*` 兼容
- 验收：接口 51 条 + v2 40 条 + 重置 13 条 + 前端回归 60 条 + 主控独立 34 条，全部实测通过（见 `test/ACCEPTANCE.md`）
